## 0-1. 다음 명령 (끊겼을 때)

```sh
cd argus/ksemi/tools
tail -3 /tmp/ksemi_reports.log /tmp/ksemi_contracts.log   # 수집이 살아 있나
python3 ksemi_reports.py --write                          # 캐시가 있으면 빠르게 이어받는다
python3 ksemi_contracts.py --all --write
python3 ksemi_page.py --all                               # 렌더
python3 -m unittest discover -s tests
```

수집은 **캐시를 먼저 본다** — 다시 돌려도 빠진 것만 받는다(실패는 캐시하지 않는다).

## 2. 결정과 근거

- **스펙의 KIND 업종명 `반도체 제조용 기계 제조업`은 KIND에 없다**(2026-09-11 실측, 전체 2,759행).
  KIND 업종은 그보다 굵다 — 장비사는 `특수 목적용 기계 제조업`(169), 부품사는 `반도체 제조업`(74)·
  `전자부품 제조업`(136)·`측정, 시험, 항해, 제어 및 기타 정밀기기 제조업; 광학기기 제외`(31)·
  `기타 비금속 광물제품 제조업`(티씨케이)·`기타 금속 가공제품 제조업`으로 **흩어져 있다**.
  → 업종 단독 필터는 불가. **업종 후보 × 주요제품 어휘 × 지정 × 본문 승격(④)** 네 경로로 짠다.
- 산업 특성 1(수주잔고) — **확인**. 단 회사마다 표 모양이 다르다(원익IPS 총액형 ↔ 한미반도체 단일계약형).
  잔고를 안 적는 회사가 실제로 있다(한미반도체 잔고 칸 `-`) → `미공시`로 남긴다.
- 산업 특성 2(매출인식 시점) — **확인**(원익IPS 설치완료). 사업보고서 주석에서만 받는다.
- 산업 특성 3(고객 집중·익명) — **확인**(원익IPS A사 49.0%).
- 산업 특성 6(수출/내수) — **확인**(II-4 매출실적에 수출·내수 행이 나뉘어 있다).
