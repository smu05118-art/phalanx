# 🔧 한국반도체장비 (`argus/ksemi`)

국내 상장 반도체 **장비사**와 **장비 부품·부분품사**(챔버·정전척·샤워헤드·쿼츠·세라믹·펌프·RF)를
전수로 모아, 이 산업의 축인 **수주잔고**와 **그 잔고가 매출로 바뀌는 시점**으로 읽는다.

소자(메모리·파운드리)·설계(팹리스)·유통은 이 탭의 대상이 **아니다** — 그쪽은 장비사의
고객이다. 대상은 장비·부품·공정 서비스다.

## 화면

| 페이지 | 무엇 |
|---|---|
| `index.html` | 허브 — 수주잔고 상위 카드(잔고 · 잔고/매출 배수 · 매출인식 기준 · 최대고객 비중), 공정 13단계별 회사 수·잔고 합, 최근 대형 수주 |
| `<종목코드>/index.html` | 회사 — 잔고 롤포워드 8분기 · 품목별 수주 · 제품별 매출 · 수출/내수 · **매출인식 기준 원문 인용** · 주요 고객 · 계약 공시 · 공정 단계 태그 · **원문에 이름이 나오는 상장사** · 같은 단계 부품사 |
| `parts.html` | 팹 공정 흐름 인포그래픽 — 단계를 누르면 그 단계 장비사, 한 번 더 들어가면 부품과 부품사 |
| `coverage.html` | 모집단 전수와 편입 근거, ④ 본문 탐색 승격·배제, ④-1 보류 재판정(원문 인용), ⑤ 원문 언급 지도, **수주표 미공시 회사도 사유와 함께** |

## 이 탭을 읽는 법

**수주잔고만 보면 안 된다.** 장비는 인도 → 설치 → 검수(SAT)까지 시간이 걸리고, 매출을
어느 시점에 인식하는지가 회사마다 다르다. 같은 잔고라도 인식기준이 '설치완료'인 회사와
'인도'인 회사는 매출로 잡히는 시차가 다르다. 그래서 카드에 잔고와 **인식기준을 같이** 싣는다.

**잔고가 비어 있는 것도 정보다.** 한미반도체는 수주상황 표에 *"계약 내용은 고객의 투자
정보 등이 노출될 수 있어 공시된 내용 외에 기재하지 않았습니다"* 라 적고 공시된 단일계약만
싣는다 — 잔고 칸은 `-` 다. 이런 회사는 '미공시'로 남기고 커버리지에 사유와 함께 모아 둔다.
**지어내지 않는다.**

**'경쟁사'와 '고객'은 본문에서 갈린다.** 회사들은 정기보고서에 서로의 이름을 적는다. 미래산업
「Test Handler를 공급하고 있는 업체는 미래산업(주), (주)제이티, (주)테크윙」은 경쟁사 목록이고,
뉴파워프라즈마 「장비 제작사는 국내의 원익IPS, 주성엔지니어링…」은 자기 RF 제너레이터가 들어가는
전방 장비사다. 목록에 자기 이름이 있는지로 가르고, 못 가르면 「업체나열」로 남겨 원문을 보여 준다.

**고객은 대개 익명이다.** 주석이 고객을 'A사'로 적으면 화면에도 익명이라 적는다. 실명을
추정하지 않는다.

**단위를 못 읽은 값에는 경고가 붙는다.** 표의 단위 캡션(백만원·천원·원)을 표마다 읽어
정규화하고, 읽지 못하면 값 옆에 `단위 미확인` 이 뜬다(fail-closed).

## 데이터 원천

전부 DART 공시 원문이다. **API 키를 쓰지 않는다**(무키 3단 경로).

- 정기보고서 II-4 「수주상황」 — 수주총액 · 기납품 · 수주잔고
- 정기보고서 II-4 「매출실적」 — 제품별 매출 · 수출/내수
- 정기보고서 III 주석 「수익」 — 매출인식 시점(원문 인용) · **사업보고서에만 있다**
- 정기보고서 III 주석 「주요 고객에 대한 정보」 — 고객별 매출(당기)
- 수시공시 「단일판매ㆍ공급계약체결」(I001) — 상대 · 금액 · 기간 · 공급지역
- KRX KIND 상장법인목록 — 모집단 · 업종 · 주요제품

방법과 원문 근거, 파서가 피하는 덫은 [`LOGIC.md`](LOGIC.md) 에 있다. 인수인계는
[`HANDOFF.md`](HANDOFF.md).

## 다시 만들기

```sh
cd argus/ksemi/tools
python3 ksemi_universe.py --write     # KIND → 후보 모집단
python3 ksemi_scan.py --write         # II절 본문 → 편입/보류/배제
python3 build_dicts.py --write        # 공정 13단계·부품 사전, 종목별 태그
python3 ksemi_contracts.py --all --write
python3 ksemi_reports.py --write      # 8분기 수주상황·매출실적 + 사업보고서 주석
python3 ksemi_peers.py --write         # II절 본문의 상장사 이름 언급 → 관계(무접속)
python3 ksemi_page.py --all           # 허브·회사·커버리지
python3 ksemi_parts.py --write        # 팹 공정 흐름
python3 -m unittest discover -s tests
```

파이썬 3.9, **표준 라이브러리만**. 수집은 캐시를 먼저 보므로 다시 돌려도 빠진 것만 받는다
(실패는 캐시하지 않는다). 원문 절 HTML은 `tools/assets/cache/` 에 남지만 커밋하지 않는다 —
커밋하는 것은 파싱 결과 JSON이다.

DART는 **공인 IP 단위**로 막는다. 수집기를 여러 개 띄워도 `kce_fetch` 의 파일 락이 프로세스
사이 요청 간격까지 묶지만, 동시에 3개를 넘기지 마라.
