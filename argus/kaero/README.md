# 한국우주항공 (KAERO) — ARGUS 하위 대시보드

국내 상장 우주항공 기업의 **수주**를 이 산업의 축으로 읽는다 — 통화 · 영역 · 계약 성격 · 고객.
체계업체(한국항공우주·한화에어로스페이스)뿐 아니라 **부품사까지** 전수로 담는다.
이름으로 넣지 않고 원문 근거로 넣는다.

- 허브 `index.html` · 커버리지 `coverage.html` · 부품 인포그래픽 `parts.html` ·
  회사 `<종목코드>/index.html`
- 원천은 DART **정기보고서 「II-4 매출 및 수주상황」**(과 XII 상세표)과
  수시공시 「단일판매ㆍ공급계약체결」, KRX KIND 상장법인목록. API 키를 쓰지 않는다.

## 왜 축이 조선·방산과 다른가 (원문 실측 — `tools/FINDINGS.md`)

1. **통화가 표마다 다르다.** 아스트(067390)는 `1) 국외수주현황 (단위 : USD )` 와
   `2) 국내수주현황 (단위 : 원)` 두 표를 나란히 싣는다. 표를 하나만 고르면 27억달러짜리
   회사가 2.7억원짜리가 된다. → **통화별로 모아 싣고 환산하지 않는다.**
2. **계약 원장이 정기보고서 안에 있다.** 계약 공시는 표본 중앙값 **연 0.75건**뿐이다
   (LTA가 기종 단종까지 자동 연장돼 새로 공시할 일이 드물다). 대신 II-4 수주표가
   계약 한 줄씩(수주일자·납기·총액·기납품·잔고) 나온다 — 여기가 뼈대다.
3. **RSP가 실재한다.** 한화에어로 「4. 수주상황(상세)」에 `한화테크윈(주), 국제공동개발사업
   계약 (PW GTF RSP)` 이 **납기 2060.12** 로 적혀 있다. 45년짜리 수익분배 계약이라
   일반 수주와 이익 성격이 다르다.
4. **고객이 실명이다.** 아스트 수주표의 품목 열이 곧 발주처다(`SPIRIT`·`EMBRAER`·`IAI`·`RUAG`).
   하이즈항공 각주는 `BOE(Boeing Commercial Airplanes)` 로 약칭을 풀어 둔다.
5. **겸업사는 부문을 갈라야 한다.** 한화에어로 수주표 114.9조 중 항공은 32.3조뿐이고
   해양 33.0조(kship)·방산 46.8조(kdef)가 섞여 있다. 세 탭이 같은 돈을 세 번 세면 안 된다.

## 축 — 무엇을 어디서 읽는가

| 축 | 원천 | 등급 |
|---|---|---|
| 수주잔고·기납품 | II-4 수주상황(통화별) | A — 표에 적힌 값 |
| 계약 원장(수주일·납기·금액) | II-4 수주표의 `item` 모양 행 + XII 상세표 | A |
| 부문 매출(내수/수출) | II-4 매출실적 | A |
| 고객 | II-4 주요 매출처 표 · 수주표 품목 열 · 계약공시 상대 · 본문 문구 | A→B, 약칭 해석은 C(추정) |
| 영역(기체구조물·엔진/RSP·MRO·방산항공·우주) | 품목·부문 이름 문구 | C — 문구 분류 |
| 계약 성격(RSP·PBL·LTA·개발·양산) | 계약명 문구, 없으면 수주~납기 10년 이상 | C |
| 통화 | 표의 단위 캡션 | A |

**싣지 않는 것**: 환산 금액(공시에 환율이 없다) · 환헤지 여부(II-4 본문에 문구가 없다) ·
수량/shipset(수주표 수량 열이 `-` 다).

## 화면

- **허브** — 회사 카드(통화별 잔고·커버리지·수출비중·영역·고객), 영역/계약성격별 잔고,
  고객 표, 큰 계약 줄 30건, USD 잔고 환율 민감도 각주.
- **회사** — 잔고 롤포워드(통화마다 한 줄) · **다른 탭과 겹치는 부문** · 계약 원장 ·
  계약 성격 구성 · 통화 구성 · 부문 매출 · 고객(근거 등급) · 부품 칩 · 수시공시 계약.
- **커버리지** — 모집단 네 겹의 편입 근거, ④ 본문 탐색의 승격/제외/실패, 그리고
  **못 읽은 것**(단위·통화를 확인 못 해 금액으로 싣지 않은 표) 목록.
- **인포그래픽** — 여객기·터보팬 엔진·위성·발사체 모식도 → 영역 → 부품 → 회사 → 고객.

## 만들기

```sh
cd argus/kaero/tools
python3 build_dicts.py --write                 # 분류 사전(교차참조 검증 포함)
python3 kaero_scan.py --scan                   # ④ 본문 탐색(느리다 · 후보 74사)
python3 kaero_universe.py --write              # 모집단
python3 kaero_contracts.py --collect && python3 kaero_contracts.py --build
python3 kaero_reports.py --collect --n 6 && python3 kaero_reports.py --build --n 6
python3 kaero_suppliers.py --build
python3 kaero_page.py --all && python3 kaero_parts.py
python3 -m unittest discover -s tests
```

판정 규칙은 `LOGIC.md`, 원문 실측은 `tools/FINDINGS.md`, 인수인계는 `HANDOFF.md`.
