# 웨이브 SCOUT — 다른 수주기반 섹터 발굴 (보고서만, 탭은 만들지 않는다)

## 실행 규약 (웨이브 에이전트용 — 러너가 이 파일을 통째로 읽힌다)

- 작업 디렉터리는 **이 클론 하나뿐**이다. `~/phalanx`(운영)과 `~/phalanx-llm-work` 는 **절대 건드리지 마라**.
- **`git push` 금지** — 이 머신엔 자격증명이 없다. 대신 **자주 로컬 커밋**하라(맥미니가 가져가 푸시한다).
  커밋에는 네 산출 경로만 담는다. 메시지는 한국어, 끝에 `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.
- **체크포인트**: 진행 상황을 `<산출 디렉터리>/tools/PROGRESS.md` 에 계속 갱신하라(단계·완료·남은 일·다음 명령).
  패스가 끊겨 다시 불려도 그 파일과 `git log` 로 이어서 한다. 같은 일을 두 번 하지 마라.
- **병렬**: 서로 의존하지 않는 일(모집단·파서·분류 사전·페이지·문서·테스트)은 Task 서브에이전트를 여러 개
  동시에 띄워라. 단 DART를 두드리는 파이썬 수집기 프로세스는 동시 3개를 넘기지 마라(요청 게이트가 총 요청률은
  묶지만 캐시 경합을 피한다).
- 파이썬은 3.9(CLT), **표준 라이브러리만**. `pip install` 금지. API 키를 쓰지도 만들지도 마라.
- 가설을 코드로 굳히기 전에 **실제 DART 원문 2~3건을 직접 열어 확인**하라. 이 문서의 산업 특성도 원문에서
  확인되면 쓰고, 아니면 "원문에서 확인 못 함"이라 적고 다른 축을 찾아라.
- 사람에게 묻지 말고 원문 근거로 판단하고, 근거를 문서에 남겨라.
- **완전히 끝났을 때만** `/tmp/scout.done` 에 한 줄 요약을 써라(아직 남았으면 쓰지 마라).

목표: 건설(kce)·조선(kship)·방산(kdef)·반도체장비(ksemi) 말고 **한국 상장사 중 수주(백로그) 기반으로
읽어야 하는 산업**을 원문 증거로 찾아 우선순위를 매긴다. 다음 라운드의 탭 스펙 초안까지 쓴다.

## 방법 (추측 금지 — DART로 센다)

1. `argus/kce/tools/kce_universe.py` 로 KIND 전 상장사(업종·주요제품)를 받는다.
2. 업종별로 표본을 뽑아(업종당 최대 8사, 시총·매출 큰 순이 아니라 **업종 대표성** 기준으로 고르고 사유를 적는다)
   최신 정기보고서 II 절을 읽어 **수주상황 표의 존재와 모양**을 확인한다:
   - '수주상황'·'수주잔고'·'수주총액'·'계약잔액' 표가 있는가
   - 잔고 금액 / 연매출 배수는 얼마인가(몇 년치 일감인가)
   - 계약 기간이 다년도인가, 단일 계약이 매출의 몇 %인가
   - 수시공시 「단일판매ㆍ공급계약체결」 건수(최근 2년)
3. 업종별로 집계해 **수주기반 점수**를 만든다(공시 회사 비율 · 잔고/매출 배수 중앙값 · 계약공시 빈도).
   점수 공식과 각 항목의 출처를 문서에 적어라(재현 가능해야 한다).
4. 후보로 반드시 확인할 것(있으면 근거와 함께, 없으면 왜 아닌지):
   원자력·발전기자재 · 전력기기(변압기·차단기) · 이차전지 장비 · 디스플레이 장비 · 철도차량 ·
   우주/항공부품 · 해상풍력 · 플랜트·EPC · 환경/수처리 · 스마트팩토리/물류자동화 · 의료기기 · 통신장비.
5. 각 후보 산업의 **산업 특성 축**(조선의 선종·선표·환헤지에 해당하는 것)을 원문에서 찾아 적는다.
   축이 안 나오면 그 산업은 탭으로 만들 가치가 낮다고 적어라.

## 산출물

- `argus/_specs/scout_report.md` — 업종별 표(수주 공시 비율·잔고/매출·계약공시 빈도·점수·대표 종목),
  상위 3개 산업의 **탭 스펙 초안**(kdef.md 형식: 산업 특성 5~7줄, 데이터 원천 표, 분류축, 화면, 모집단 규칙),
  그리고 "탭으로 만들지 말 것" 목록과 이유.
- `argus/_specs/scout_evidence.json` — 회사별 원천 근거(종목·rcpNo·표 유무·잔고·매출·배수). 재현용.
- 커밋·푸시(`argus/_specs/` 만). 끝나면 `/tmp/scout.done` 에 상위 3개 산업과 한 줄 이유.

표본은 **200사 이내**로 잡아라(DART 게이트가 요청률을 묶으므로 다른 웨이브와 함께 돌아도 안전하지만,
쓸데없이 많이 긁지 말 것). 못 읽은 회사는 '미확인'으로 남기고 숫자에서 빼라 — 추정으로 채우지 말 것.
