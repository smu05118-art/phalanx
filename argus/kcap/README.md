# 🏭 한국화학 캐파 (argus/kcap)

국내 상장 화학사의 **생산능력(톤/년)·생산실적·가동률**을 DART 정기보고서에서 전수 수집하고, 품목을 ARGUS 스프레드(argus/kchem)에 연결해
**분기 스프레드 마진 프록시**와 보고 영업이익 보정, **다음 분기 추정**을 만든다. 캐파 증설·축소는 연간 열 비교와 거래소 수시공시로 매일 자동 갱신된다.
라이브: `https://smu05118-art.github.io/phalanx/argus/kcap/`

| 페이지 | 내용 |
|---|---|
| `index.html` | 후보·수집·편입 KPI, 편입 회사 카드(매핑 캐파·커버리지·다음 분기 프록시·보정 추정), 최근 캐파 변동, 최근 이벤트 공시 |
| `<종목코드>/index.html` | 회사 — 다음 분기 추정 상자(가정·주의 포함), 분기 프록시 vs 보고 영업이익 차트·표, 제품→스프레드 매핑(구성비·가동률), 생산능력 이력(연간 열 kt/년·변동), 이벤트 공시, 읽은 보고서 |
| `products.html` | 스프레드 제품 토큰별 → 회사 귀속 캐파·구성비 → 연결 스프레드 |
| `changes.html` | 연간 생산능력 변동(±5%↑), 올해 연환산 vs 연간(저신뢰), 이벤트 공시(신규시설투자등·생산중단·영업정지) |
| `coverage.html` | 모집단 전수(후보·제외·수집·편입)와 근거, 미매핑 톤 품목(사전 보강 대상) |

## 읽는 법

- 생산능력은 **보고서 당기 값의 연환산**이다(근거 열에 '기간비례→연환산' / '연간 명판 그대로' / '연환산 근거 없음'). 직전 연간 열과 비교해 판정하며, 원문 두 값은 회사 페이지 이력 표에 그대로 있다.
- 가동률은 보고값이 없으면 생산실적 ÷ (연간 생산능력 × 개월/12) 로 계산한다(`computed`). 보고서 안에 직전 연간 열이 없는 표(국도화학)는 원장의 직전 연도 값으로 연환산 여부를 판정한다.
- 제품 매핑과 바스켓 구성비는 **추정**이다(`tools/assets/product_map.json`). 미매핑 품목은 숨기지 않고 '미매핑' 으로 보이며 프록시에서 빠진다(커버리지 %).
- 프록시는 영업이익이 아니다 — 스프레드 × 물량 × 환율의 총마진 근사다. 보고 영업이익과의 보정(OLS)이 있고 설명력(R² ≥ 0.3)·커버리지(≥ 30%)·규모(프록시가 영업이익의 20% 이상)를
  모두 넘을 때만 '보정 영업이익 추정' 억원을 내고 R²·범위(±1.64σ)를 같이 본다. 못 넘으면 같은 수치를 사유와 함께 '참고만' 으로 흐리게 보인다(정유·지주 손익이 지배하는 GS·S-Oil 등).
- 가동률은 품목 행에 없으면 사업장 집계(대한유화) → 회사 중앙값 → 80% 순으로 가정하고 '가정: 가동률' 로 표시한다. 유틸리티·비화학 품목(증기·전기·소스 …)은 커버리지 분모에서 뺀다.
- 스프레드 원장(argus/kchem)은 2026-08-24 이후 멈춰 있다. 그 뒤 분기의 프록시는 최근 13주 평균 가정이고 정지 주수가 표시된다.
- LG화학(석유화학)·효성화학·코오롱인더는 생산능력을 금액(백만원)으로만 공시해 톤 모델이 불가하고, SK이노베이션·태광산업은 품목을 뭉뚱그려 공시한다 — 커버리지 페이지의 '검토·제외'.

## 실행

```sh
cd argus/kcap/tools
python3 -m unittest discover -s tests -p 'test_kcap_*.py'       # 파서·원장·모델 계약(fixture, 네트워크 없음)
python3 kcap_universe.py --write                                 # KIND → assets/universe.json (1요청)
python3 kcap_capacity.py --all --quarter 2026Q2                   # 후보 전수의 생산설비 절(캐시 우선, DART 순차)
python3 kcap_capacity.py --stocks 011170,011780 --quarter 2025Q4  # 과거 분기(이력)
python3 kcap_events.py --stocks 011170,011780 --since 20240101    # 이벤트 공시
python3 kcap_fin.py --stocks 011170 --quarters 2024Q3..2026Q2 && python3 kcap_fin.py --stocks 011170 --build
python3 kcap_build.py --changes                                   # 원장 조립(요청 0)
python3 kcap_model.py --list                                      # 매핑·프록시·보정·추정(요청 0)
python3 kcap_page.py                                              # 페이지(요청 0)
python3 kcap_run.py --daily [--history]                           # 위 수집 단계를 워크플로 순서로
```

표준 라이브러리만(Python 3.9+), API 키 없음, DART 는 `kce_fetch` 의 프로세스 간 요청 게이트를 따른다. 원문 캐시 `tools/assets/cache/` 는 git 에 넣지 않는다(워크플로는 actions/cache).
판정 규칙은 [LOGIC.md](LOGIC.md), 상태·남은 일은 [HANDOFF.md](HANDOFF.md).
