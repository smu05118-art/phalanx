## 3. 계산 로직 (전부 코드에서 추출한 수식)

### 3.1 III-8 분해 `decomp(b)` — 막대 합 ≡ 수주총액 보존
```
완성액 comp = round(tot × pr/100);  회수 rec = comp − ub − rc;  잔액 bal = tot − comp
손상대손 imp = |ubimp| + |allw|   (원문 부호가 회사·분기별로 뒤죽박죽 → 절대값 통일)
미청구순 ubNet = ub − |ubimp|;  미수금순 rcNet = rc − |allw|
대손율 bad = (|ubimp|+|allw|) / (ub+rc) × 100
```
**결측 처리 두 갈래**(코드 대조 확인):
- `ub`·`rc`가 null이면 **0으로 강제**(`b.ub[i]||0`)해 `rec = comp`(전액 회수)로 그린다.
  `tot!=null` 4,654셀 중 **3,536셀(76%)에서 발동**하는 가장 흔한 경로다.
- `tot==null` → 전부 null. `pr==null` → `bal`만 `round(tot)`로 남고
  **`imp`·`ubNet`·`rcNet`·`bad`도 전부 null**이 된다(막대는 잔액만, 손상·미청구 구간은 사라짐. 해당 9셀).

III-8 진행률이 정수 공시라 `rec<0` 가능(II-4 완성공사액 대비 오차 중앙값 1.0%).

### 3.2 XI-1 분해 `xipDecomp(X)` — 막대 합 ≡ 계약금액
```
대금수령(기성) recv = min(S,R);  선수금 adv = max(R−S,0);  매출채권 ar = max(S−R,0)
잔액 bal = C − max(S,R);  진행률 pr = S/C×100 (C>0)      [S=supCum, R=recvCum, C=amt]
```
C만 null(외화 표기, UAE 원전) → bal·pr만 null. C만 있고 S=R=0 → 진행 0% 전액 잔액(미착공 정비사업 84건).

### 3.3 분기 매출인식액(추정)
`rev.diff[k] = cmp[k] − cmp[k−1]` (연속 두 값 필요). matrix의 `data-v`가 이 배열과 **완전 일치**(중복 임베드).
환율·지분율 별도 적용 없음 — 공시 완성공사액 증분 그대로.

### 3.4 공기 대비 배지
`prC` = 통합 S-curve p50을 사업장 공기축(`sd→ed`)에 리베이스한 기준 공정률.
`gap = pr[i] − prC[i]`, i = 구간 마지막 실측 분기(우선순위: 실측 → 보전값(fcst 제외, `~` 접미) → III-8 진행률(별도 우선)).
색: g<−15 빨강 / g<−5 주황 / 그 외 청록. 완공예정일 개정(`prCv` 2개 이상)이면 개정판마다 배지를 `›`로 연결.
**fcst 제외 이유**: 모델 값으로 모델 격차를 재는 순환 방지.

### 3.5 집계 규칙 (§5에서 수치 검증됨)
- `summary.rows[ent][k]` = Σ sites `s.bal` — **실측 셀(sFilled null)만, agg 제외**. 단 `src='공시총계'`(hec)는
  사이트 합이 아닌 공시 총계 직접 채택(개별 표 미기재 소규모 사업장 포함 → 항상 Σsites보다 큼).
- `revSummary.rows[ent][k]` = Σ sites `rev.diff[k]` (agg 제외; 보전값 포함, `filled`로 표시).
- 귀속 법인은 **그 분기 원문 표기 법인** — `sites[].ent`는 정규화 라벨이라 표시법인 변경 사이트(ev f=표시법인 21건)에서
  법인 간 어긋나되 그룹 합은 보존(gse 자이 96,960 상쇄 사례로 정확 재현).
- `total` = Σ법인 rows (오차 0). `dom+ovs = rows`도 성립하며, 어긋나는 셀은 **정확히 4개이고
  전부 ±1 반올림 오차**다(현대건설 2021Q4·2022Q4·2025Q4, 현대엔지니어링 2022Q3).
  송도랜드마크시티는 `dom`·`ovs`가 전 구간 null이라 애초에 부등식이 성립하지 않는다(불일치가 아니라 부재).
- 국내/해외·사업부문·관계사 소행은 **병렬 분해**(교차분류 아님) — 함께 더하면 이중계산.
- 대조행: `SUM.total[k] − note.simple[k]`, |d|>3백만원이면 붉은 셀. `consol = simple − intra`.

### 3.6 coRev 파생 관계 (검증 결과 포함)
- `i4_adj = i4 − Σ i4_seg:*` (연결조정 차액; sct·dwe·gse 18/18 정확).
- `i4 = i4_dom + i4_ovs`: sct·gse 정확. **dwe는 지역분해가 연결조정 전 기준**(차액 ≡ i4_adj, 18/18).
  **ipark는 부분 분해라 미성립**(dom+ovs가 i4의 30% 수준). dle은 수천 단위 오차(별도 기준 표).
- `con = con_dom+con_ovs`(sea 19/19), `sep = sep_dom+sep_ovs`(hec·sea·dwe 정확), `con/sep = Σseg`(hec·sea 정확).
- 추정/실제 비율표: `ratio = revSummary[분자] / coRev.series[분모] × 100` — 행 구성은 `REVCFG.ratio`가 정의.

### 3.7 S-curve (curve.html의 `const D`)
- **모수적 피팅 없음** — 경과율 버킷별 **경험적 분위수** 테이블. `D[키]` 행 = `[버킷중심 x, p10,p25,p50,p75,p90, n(사이트 수)]`.
- x = 공기 경과율 `(관측시점−착공)/(완공예정−착공)` (1.3까지 — 지연 현장 포함), y = 진행률 = `cmp/amt`.
- 버킷 폭 0.05 (표본 성긴 `해외×건축주택`만 0.10). 세그먼트 = 지역×공종 6 + 국내/해외/전체 = 9곡선.
- 7사 풀링(회사별 분리 시 공사 후반 표본 공백). n<20 버킷은 경고 표시. n=0 꼬리 버킷은 1.0 수렴 외삽.
- 속도 차트 = 분위수 이산 미분 × 0.05 정규화("공기 5%당 %p").

### 3.8 backtest (워크포워드)
기준시점 2023Q4~2025Q2 각각에 대해 **그 시점까지 공시된 것만으로** S-curve 재적합 → T+1~T+4 진행률 예측
(도급액 증액 반복 사업장은 「추세」 = 현재 속도 직선 연장) → `매출 = 진행률 증분 × 기준시점 도급액`.
지표: 진행률 절대오차 중앙값 / 편향(T+1 +0.16%p → T+4 +3.29%p 단조증가 = 계통 과대예측) / 매출 괴리 `예측÷실측−1`.
sct 전체 +16.8% 과대, 진행률 80% 이상 구간 +74.2%(최악) — 후반부 곡선의 과대예측이 알려진 약점.

## 4. 페이지별 로직 요약

- **index**: 3열 그리드(사이드바 목록+필터 / 중단 4개 집계 섹션 / 우측 사업장 상세 차트 4종).
  차트: II-4 누적바+진행률/기준공정률 점선, III-8 별도·연결 5단 누적바+대손율, XI-1 4단 누적바.
  네 차트 y축 상한 공유(`axMax×1.08`) — 도급액/수주총액/계약금액 기준 차이를 막대 높이로 직독시키는 설계.
  셀 표식 우선순위: 수동정정(청록 실선) > 추정배분(보라) > p8(초록) > interp(주황) > fcst/bcst(분홍), xi1(민트).
  키보드 ↑↓/Space, 즐겨찾기, 그룹 접기, 주석 모달, 해시 라우팅 없음(첫 사업장 자동 선택).
- **matrix**: 사업장×23분기 매출증분 매트릭스(전부 프리렌더). 그룹 = 법인·지역·공종. 필터 시 보이는 행만 재합산.
- **trace**: 원문 표기 문자열의 출처×분기 매핑 존재표(II-4 칸은 실측만 채움). DART 링크 없음 —
  (출처 절 × 분기 × 원문 표기) 3좌표로 원본 위치를 특정하는 설계.
- **headers**: 파서가 채택한 표의 머리행을 분기마다 기록한 회귀 감시 장치. 비교 키 = `tag + '#' + 분기 내 순번`.
  → 파서 사양은 UPDATE.md §3에 이관.
