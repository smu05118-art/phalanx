# ⚡ 한국전력기기 (`argus/kgrid`)

전력기기·전력망 상장사를 **수주기반**으로 보는 탭이다. 변압기·차단기·배전반·개폐기·전력변환·
전선·계전기·금구류를 만드는 회사를 KRX 전 상장사에서 추려, DART 정기보고서
「II. 사업의 내용」과 수시공시「단일판매ㆍ공급계약체결」만으로 만든다. **API 키를 쓰지 않는다.**

## 이 탭을 읽는 법

이 산업은 **잔고가 짧은 것이 특징**이다. 그래서 "수주잔고 몇 조"라는 숫자를 회사끼리 그냥
견주면 안 된다. 세 가지를 같이 보라.

1. **커버리지(잔고 ÷ 직전 사업연도 매출, 년)** — 몇 년치 일감인가.
   초고압 변압기는 **장납기**(배수 1년 초과, 백로그 산업)고 배전기기는 **회전**(배수 1년 미만,
   받아서 몇 달 안에 내보낸다)이다. 허브 첫 화면의 이분 막대가 이것이다.
   *배수가 0.5년이라고 나쁜 회사가 아니다* — 회전 산업에서는 그게 정상이다.
2. **잔고 입도** — 표의 한 행이 계약인가 사업부문 합계인가. 이 산업은 **부문 합계가 대부분**이다
   (HD현대일렉트릭은 1행이 잔고의 100%, 엘에스일렉트릭은 T&D 1행이 98%). 회사 표 옆의
   `부문 합계 · 최대행 98%` 배지가 그 뜻이다. 계약 단위 원장은 수시공시로만 만든다.
3. **통화** — 잔고를 외화로 공시하는 회사가 있다(일진전기 `(단위 : 천USD )`). **환산하지
   않는다** — 보고서에 기말 현물환율이 없다. `$1.94bn` 처럼 통화를 붙여 보이고, 원화 합계와
   커버리지에서는 뺀다.

## 화면

| 파일 | 무엇 |
|---|---|
| `index.html` | 허브 — 장납기:회전 이분 막대 · 제품군별 잔고 · 수요 낱말 순위 · 회사 표·카드 |
| `grid.html` | 전력망 단선도(발전→승압→송전→변전→배전→수용가). 영역을 누르면 그 자리의 제품군과 회사 |
| `coverage.html` | 모집단 전수와 편입 근거 · 수록 상태 · **못 싣는 것과 그 이유** |
| `<종목코드>/index.html` | 회사 — 잔고 추이·롤포워드 · 수주표 원문 행 · 부문/지역 매출 · 매출처(근거 등급) · 계약 공시 · 수요 낱말 원문 인용 · 되짚기 |

## 고객이 실명이다

이 산업의 특징이다. HD현대일렉트릭 주요매출처 표에는 `NextEra Energy 15.9%`,
`사우디 전력청 5.0%` 가 **금액까지** 적혀 있다. 다만 같은 표에 네 가지가 섞이므로 배지로 가른다.

| 배지 | 뜻 |
|---|---|
| 실명 | 회사·기관 이름이 그대로 적혔다 (`NextEra Energy`) |
| 고객분류 | 고객이 아니라 **분류**다 (`전력 산업`, `조선회사/EPC`, `대리점`) |
| 관계회사 | 자기 종속회사다 — 연결 매출과 겹친다 (`LS ELECTRIC AMERICA 41.7%`) |
| 익명 | `A사` 처럼 가렸다 |

비중은 대개 **그 사업부문·종속회사 안에서의 비중**이며 회사 전체 대비가 아니다. 또
"연결 매출의 5% 이상만 기재"라는 주석이 붙으므로 최대고객 비중은 **하한**이다.

## 파이프라인

```sh
cd argus/kgrid/tools
python3 kgrid_dicts.py --write         # 제품군·수요처 사전 + 단선도 영역(교차 검증)
python3 kgrid_universe.py --write      # 모집단 — KIND 업종 4갈래 + 제품 어휘 + 지정 + 탐색
python3 kgrid_scan.py --probe --build  # ④ 본문 탐색으로 부품사 승격·오탐 제외
python3 kgrid_contracts.py --collect && python3 kgrid_contracts.py --build
python3 kgrid_reports.py --collect --n 6
python3 kgrid_reports.py --reparse     # 파서를 고친 뒤 — DART를 다시 긁지 않는다
python3 kgrid_reports.py --build --n 6
python3 kgrid_page.py --all
python3 -m unittest discover -s tests
```

`tools/` 는 배포물이 아니다(`_config.yml` 의 exclude). 자동 갱신은
`.github/workflows/update-kgrid.yml`(일 1회, `concurrency: kship-dart`).

## 더 읽을 것

- `tools/FINDINGS.md` — **원문을 직접 열어 확인한 것**. 이 탭의 모든 판단 근거가 여기 있다.
- `LOGIC.md` — 값이 어떻게 만들어지는가(파서 규칙과 fail-closed 지점).
- `HANDOFF.md` — 지금 상태·남은 일·재현 명령.
- `tools/PROGRESS.md` — 체크포인트.

참고용이며 투자조언이 아니다.
