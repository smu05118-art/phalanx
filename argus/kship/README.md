# 한국조선 (KSHIP) — ARGUS 하위 대시보드

국내 상장 **조선사·조선기자재사**의 수주를 산업 특성대로 읽는다. 건설 탭(`argus/kce`)의 DART 수집·파서를
그대로 재사용하고, 조선에만 있는 축을 새로 만들었다.

진입: [`argus/index.html`](../index.html) 헤더의 **⚓ 한국조선** → [`index.html`](index.html)
인수인계·실행 순서: [HANDOFF.md](HANDOFF.md)

## 축 — 무엇을 어디서 읽는가

| 축 | 원천 | 화면 |
|---|---|---|
| 수주잔고·신규·기납품(매출인식) | 정기보고서 II-4 **부문 롤포워드**(원화) | 조선사 페이지 롤포워드 표·누적 막대 |
| **선종·척수·인도시점·상대·지역·대금조건** | 수시공시 「단일판매ㆍ공급계약체결」(척당) | 선종 구성 · **선표**(계약기간 종료일→분기) · 계약 표 |
| 환노출·**환헤지** | II-5 위험관리 · 주석 「파생금융상품」(통화선도 명목액·평균만기) | 환율·환헤지 카드 — 비율은 회사가 공시한 약정환율이 있을 때만 |
| **반복건조(시리즈)** | 공시에 없음 — 같은 선종·상대·지역, 수주일 180일 이내를 묶은 **추정** | '추정' 표시 |
| 기자재 **부품 분류**(대분류 14·소분류 54) | 정기보고서 II-2 주요제품 + KIND 문구 → 키워드 규칙 | 기자재사 페이지 · 인포그래픽 |
| 기자재→조선사 **연결** | 정기보고서 II 절 본문의 조선사 언급(횟수), 비중은 적힌 경우만 | 근거 등급(주요고객 주석 > 계약 공시 > 본문 언급 > KIND) |

정기보고서 수주표에 선종·척수가 **없다**는 것이 이 탭의 출발점이다(2026 반기 3사 실측). 그래서 척당 계약
공시를 원장으로 쓴다 — 계약상대는 81%가 '○○ 소재 선사'로 익명이며, 그 사실을 화면에 그대로 둔다.

## 정직성 규칙(건설 탭과 같다)

원문이 지지하는 것만 싣고, 추정은 `추정`·근거 등급으로 표시한다. 통화·단위는 표마다 읽어 정규화하며
(백만원·백만달러), 못 읽으면 `unit_seen=false`로 남긴다. 분류하지 못한 제품은 `tools/assets/unclassified.csv`에
쌓이고, 사람이 `parts_override.csv`로 지정하면 빌더가 반영한다.

## 갱신

`.github/workflows/update-kship.yml`이 매일 10:40 KST에 돈다(척당 계약 공시는 수시, 정기보고서는 분기).
DART는 동시 프로세스에 약하므로 수집기는 하나씩 돌린다.

참고용 · 투자조언 아님.
