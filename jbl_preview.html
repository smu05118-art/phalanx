01 / 기업·방법 — MJC의 틀, JEM의 신중함

Jabil은 고객 설계 기반 제조·엔지니어링 사업입니다. 통관되는 완제품 가치가 회사 인식매출과 같지 않고, 전사 매출을 서버 수출만으로 설명할 수 없습니다.

MJC에서 가져온 것

프록시 → 마진 → 조건부 전망 → 실적 후 채점의 연결. 회사 고유 회귀계수·가중치·적중률은 가져오지 않습니다.

JEM에서 가져온 것

예측력이 약한 프록시는 방향 확인에 제한. 회사 가이던스, 이익률 산술, 구조 변화와 결측을 먼저 봅니다.

Jabil에 적용한 3단계

L1 공식 가이드 / L2 산업 관측 / L3 연구 민감도. 서로 평균내거나 중복 합산하지 않습니다.

04 / 전망 — 가이던스와 재고를 같은 화면에

FY27 Q1 공식 범위의 산술

하단·중간·상단을 대응시킨 설명용 열이며 회사가 제시한 공동 확률 시나리오가 아닙니다. 매출·OP 전체 조합 OPM은 5.19–6.15%, 회사 OPM 가이던스가 아닙니다.

Q2 민감도 = Q1 가이드 × FY25/26 Q2/Q1 비율. n=2이며 FY26은 Hanley 편입 경계. 연간 잔액 평균 = (44.5 − Q1) ÷ 3. 둘 다 Q2 회사 전망·확률 구간이 아닙니다.

재고 구성 · 실측은 보존, 추정은 분리

Q4 순재고 $7.413B만 실측. 오른쪽 구성은 Q3 비중을 적용한 추정이며 원본 Q4 구성 null은 유지합니다. 충당금은 음수. 고객 소유 부품은 회사 순재고와 다른 범위입니다.

과거 사업부 · FY26 Q3

사업부 합계 $8.751B. 현재 FY27 Q1 제품 믹스나 고객 배분의 대용이 아닙니다.

구조 단절 체크

위탁 부품 전환은 gross 매출 비교를 바꾸며, 인수·매각은 기존 통관 회귀의 안정성을 깨뜨릴 수 있습니다.

05 / 하이퍼스케일러 연구 실험실

연구 추정 · 비검증 시나리오 · 확률 아님 · 검증 모델 예측 아님.
아래 기본값은 중립 산술 예시입니다. AWS/Jabil의 실제 설치량·생산 몫·인식 단가를 뜻하지 않습니다. 가정값은 회사 매출 전망이나 예측 원장에 저장·합산되지 않습니다.

매출 인식계약·인식 기준

AWS 공식 Trn3 UltraServer는 최대 144칩 참조입니다. 아래 단위는 144칩 환산단위이며 물리 랙 수가 아닙니다. Anthropic의 2026년 말 거의 1GW는 T2+T3 계획, 장기 최대 5GW는 계약 용량으로 이 산식에 넣지 않았습니다.

8개 Jabil 회계분기 가정 (칩 수, 설치 실측 아님)

인식매출 = 칩 수 ÷ 144 × 생산 몫 × 인식 단가. gross BOM 제외. 증분 OP는 이 가상 사업만의 산술이며 전사 Core OP 예측이 아닙니다. 시차로 밀린 기간 밖 금액도 별도 표시하고, 직전 기간 유입은 0으로 둡니다.

06 / 밸류에이션과 반영률

FY27 Core EPS × 사용자 배수

EPS $17.55는 연간 회사 가이드, 배율·P/E 15~25배는 임의 설명값. 시장 적정배수·목표가·투자 권유가 아닙니다. 연구 실험실 매출을 EPS에 더하지 않습니다.

컨센서스·priced-in은 보류

독립 분기 컨센서스: 미확인
최근 3개월 주가 × 컨센 리비전: 입력 미확보
모델 기대수익률·상방 확률: 미산출

MJC/JEM의 반영률 항목은 동일하게 유지하지만, 회사 가이드나 사용자 입력 주가로 검증된 시장 반영률을 대신 만들지 않습니다.

연간 이익 산술

$44.5B × Core OPM 6.1% = $2.7145B 연간 Core OP 환산. 연간 EPS는 이자·세금·주식수에 영향을 받으므로 이 수치만으로 분기 EPS를 역산하지 않습니다.

07 / 조건부 판단 — 다음 공시에서 확인할 것
