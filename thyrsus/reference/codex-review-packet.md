# 티르소스 — 외부 더블체크 요청 패킷 (Codex 등 타 도구용)

대상 파일: `thyrsus/index.html` (단일 HTML 앱, 약 3만 줄 / 300KB, 의존성 없음)
브랜치: `claude/trouble-brewing-script-1sv6lg`

## 프로젝트 개요
Blood on the Clocktower(한국어 "시계탑에 흐른 피") 사회자(Storyteller) 보조 웹앱.
참조 사이트 clocktower.teeroz.net 의 정보구조·디자인을 따르되, 사회자 편의 기능을 강화한 자체 구현.
외부 사이트의 능력 설명 산문은 복제하지 않고 공식 규칙 기반 자체 문장으로 작성함.

## 리뷰 요청 범위 (우선순위 순)
1. **규칙 정확성** — 3개 공식 스크립트(점철되는 혼란 22 / 피로 물든 달 25 / 화단에 꽃피운 이단 25) 캐릭터의
   `CHARACTERS` 배열 내 `ability` 요약과 `warn`(상호작용 주의)이 공식 규칙과 어긋나는 부분.
   특히: 오작동(중독/취함) 시 동작, 등록(register as) 재량 범위, 사망·보호 우선순위, 승리 조건 판정.
2. **밤 순서** — `EDITIONS[ed].first/other` 배열이 공식 밤 순서와 일치하는지 (여행자·전설 제외).
3. **상태 수명주기** — `addStatus/expireStatuses`의 `expiresAt` 규칙:
   중독=다음 밤 시작 시 해제, 보호=새벽(그날 낮 시작) 해제, 주인/저주/광기=다음 밤 갱신. 누수·이중 부여 여부.
4. **투표 로직**(하우스룰) — `newNomination/closeHands/closeBallot/executeNominee`:
   1차 거수(생존자 과반 ⌊n/2⌋+1) → 2차 찬반(생존자 + 투표토큰 보유 사망자), 사망 토큰 1회 소진,
   재지명 무제한, 하루 중 찬성률 최고자 처형, 동률 시 처형 없음. 경계조건(0표, 전원 기권, 토큰 복원) 검증.
5. **판정 자동화** — `doImpKill/doStepKill/teaLadyBlock/killPlayer`의 보호·면역·대체사망·계승 분기,
   좀버얼 죽은 척(fakedead), 어릿광대 1회 생존, 팡 구 점프, 탕녀 계승(생존 5+ & 정상 작동).
6. **XSS/안전성** — 사용자 입력(플레이어 이름·메모·커스텀 캐릭터)이 `esc()`를 거치지 않고 innerHTML/onclick에
   삽입되는 지점. 특히 onclick 속성 내 문자열 보간 구간.
7. **상태 지속성** — localStorage 스키마 마이그레이션(구버전 저장본 로드 시 신규 필드 누락), 클라우드 저장
   (`cloudBuildDoc`)이 동적 DOM을 정확히 비우는지.

## 실행·검증 방법
브라우저에서 파일을 직접 열면 동작함(서버 불필요). 자동 검증 스위트(Playwright):
- 시나리오+퍼징: TB 결정적 10종 + 무작위 풀게임 20판 불변식 검사
- 에디션 스모크 / 밤 위저드 / 게임 설정 위저드 / 모바일(440x956) / 타운스퀘어
검사 스크립트는 이 저장소에 포함되어 있지 않음(세션 스크래치) — 필요 시 아래 헬퍼로 직접 호출 가능:
`S`(전역 상태), `blank()`, `advancePhase()`, `nightSteps()`, `voteNotices()`, `buildChecklist()`,
`startWiz(stepId)`, `openPlayerModal(pid)`, `activeJinxes()`.

## 알려진 제약 (재보고 불필요)
- 여행자 밤 활동은 밤 순서에 자동 삽입하지 않음(황혼 직후 수동 처리 안내).
- 징크스 DB는 확신 가능한 3건만 수록(나머지는 공식 위키 확인 안내).
- 아이콘은 이모지(저작권 회피). teeroz의 webp 캐릭터 아트는 사용하지 않음.
